🏛️ Historium

Descripción: Web histórica sobre los periodos de la antigua Roma. El sistema registra los periodos romanos, de cada periodo se almacena:

-Nombre
-Año de inicio 
-Año final
-Emperador o emperadores
-Breve descripción

La web debe inicializarse con un mínimo de 4 periodos.

Funcionalidades
⏳ Periodo más largo: devuelve el periodo con mayor duración.
👑 Periodos por emperador: dado el nombre de un emperador, devuelve el periodo o periodos en los que estuvo presente.


🛠 Tecnologías
Lenguaje: PHP 8 o superior
Ejecución: navegador 


🚀 Instalación
Clonar el repositorio: git clone <url-del-repositorio>
Entrar en la carpeta del proyecto: cd Historium
Comprobar que PHP está instalado: php -v
Arrancar el servidor local: php -S localhost:8000
Abrir en el navegador: http://localhost:8000/index.php
