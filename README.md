# 🏛️ Historium

**Descripción**: Web histórica sobre los periodos de la antigua Roma. El sistema registra los periodos romanos y, de cada periodo, almacena:

- Nombre
- Año de inicio
- Año final
- Emperador o emperadores
- Breve descripción

La web debe inicializarse con un **mínimo de 4 periodos**.

- ⏳ **Periodo más largo**: devuelve el periodo con mayor duración.
- 👑 **Periodos por emperador**: dado el nombre de un emperador, devuelve el periodo o periodos en los que estuvo presente.

## 🛠 Tecnologías

- Lenguaje: PHP 8 o superior
- Ejecución: navegador

## 🚀 Instalación

1. Clonar el repositorio: `git clone <url-del-repositorio>`
2. Entrar en la carpeta del proyecto: `cd Historium`
3. Comprobar que PHP está instalado: `php -v`
4. Arrancar el servidor local: `php -S localhost:8000`
5. Abrir en el navegador: `http://localhost:8000/index.php`
